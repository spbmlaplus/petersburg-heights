# Горные просторы — сайт

Открыть: двойной клик по index.html (нужен интернет: спутник, рельеф, шрифт).
Свой ключ Mapbox (pk.…) можно вставить в config.js — без него берётся спутник из макет1.qgz.

Цвета (js/config-layers.js): синий — природа и время, оранжевый — люди прошлого, розовый — мы и сегодня, белый — рельеф и границы.

- js/config-layers.js — палитра, эпохи, истории-закладки, тексты карточек
- js/stories-data.js — тексты историй (из лонгрида исследования)
- js/app.js — карта, слои, подписи, наведение/клик/карточки, находки, истории, выноски с фото
- data/*.js — слои (EPSG:4326), media/ — фото и обложки
- tools/ — пересборка: build_data.py (слои), build_media.py (фото), build_stories.py (обложки и тексты)
